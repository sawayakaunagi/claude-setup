# local/ — 手元でだけ使う同梱物

このディレクトリの中身は **`.gitignore` で除外**されており、公開リポジトリには入りません
（この README だけが追跡されます）。

## 何を置くか

**手元では一緒に使いたいが、公開リポジトリには入れられないもの。**

| 置くもの | 理由 |
|---|---|
| ライセンス表記が無い配布物 | 再配布の可否が不明。許諾が取れるまでここに置く |
| 他者の記事・資料の写し | 著作物なので公開できない |
| 個人・組織に固有の設定 | そもそも他人に配る意味が無い |

例:

```
local/
  masao-skills/          audit-harness, audit-agent-essence, agent-essence.md など
  bestofn/               ライセンス表記なしのため公開側では参照のみ
```

## 公開側へ昇格させるとき

許諾が取れた、あるいは自分で書き直したものは、`plugins/claude-setup/` 配下へ移します。
その際は:

1. [NOTICE.md](../NOTICE.md) に帰属を追記する
2. `git status` で追跡対象に入ったことを確認する

## 逆に、うっかり公開しないために

新しくファイルを足したら、**push 前に必ず確認する**:

```bash
git status --short
git check-ignore -v local/<追加したファイル>
```

`.gitignore` は `/local/*` を除外し `!/local/README.md` だけを戻す形になっています。
サブディレクトリを足しても除外は効きますが、確認する癖をつけてください。
